Описание:
Этот проект представляет собой программу, которая будет собирать данные о самолетах в воздушных пространствах тех стран, которые вы выберете.
Установка:
1. Клонируйте репозиторий:
git@github.com:pannikolaserg-prog/E-commerce.git
Использование:
1. Откройте приложение в вашем PyCharm.
2. В модуле classes.py реализованы классы Product и Category.
3. В модуле utils.py описана функция для считывания файла .json.
4. В модуле main.py реализуется весь функционал пакетов проекта.
Документация:
Для получения дополнительной информации обратитесь к документации.
