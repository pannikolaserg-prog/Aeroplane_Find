Описание:
Этот проект представляет собой программу, которая будет собирать данные о самолетах в воздушных пространствах тех стран, которые вы выберете.
Установка:
1. Клонируйте репозиторий:
git@github.com:pannikolaserg-prog/Aeroplane_Find.git
Использование:
1. Откройте проект в вашем PyCharm.
2. В модуле utils.py реализован метод для упорядочивания данных о самолетах.
3. В модуле planes.py описана класс, который получает данные о самолетах и методы для их сравнения.
4. В модуле APIAdapter.py реализован класс для получения координат страны и информации о самолете из Api.
Документация:
Для получения дополнительной информации обратитесь к документации README.md.
